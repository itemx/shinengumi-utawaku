# セトリ作成ツール 使い方ガイド

歌枠の前に「今日なに歌おう？」を決めるためのツールです。
**SEG-V UtaList** に登録されている曲の中から、
条件で絞り込んで選ぶだけでセトリの下書きが作れます。

> 選べる曲数は固定ではなく、**日々増減します**。
> 新しい歌枠のセトリが登録されれば曲が**増え**、
> 同じ曲が別表記で重複登録されていたと判明した場合は**まとめられて減る**こともあります。

---

## はじめに知っておいてほしいこと

| | |
|---|---|
| **入口** | サイト**一番下（フッター）**の「**セトリ作成**」から |
| **データの扱い** | すべて**お使いのブラウザ内だけ**で処理されます。サーバーには何も送られません |
| **保存** | **過去のセトリは保存されません**。ページを閉じると消えます |
| **端末** | **スマホでもPCでも**使えます。移動中にスマホで組んでも OK |
| **成果物** | 最後に**コピーできるプレーンテキスト**のリストが出ます |

> 保存されないので、作ったリストは**必ず最後にコピーして**
> 配信メモや概要欄の下書きなどに貼り付けてください。

---

## 画面の見かた（PC）

画面は左右2つに分かれています。

```
┌─────────────────────────────┬──────────────────┐
│ ① 曲を探すエリア              │ ② 選択中リスト     │
│                             │                  │
│  [曲名・アーティストで検索…]   │  選択中   クリア   │
│  [全チャンネル ▼]            │  5 曲・推定 0:22  │
│                             │                  │
│  アニメ バラード ゲーム …     │  目標 [60] 分     │
│  （タグで絞り込み）           │  [指定時間まで補充]│
│                             │  [引き直す]       │
│  〇〇 曲 ←絞り込み後の曲数   │                  │
│  ☐ 曲名 / アーティスト (4:00)│  ⠿ 1 曲名 (4:00) │
│  ☐ 曲名 / アーティスト (3:31)│      アーティスト  │
│  ☐ …                        │  ⠿ 2 …           │
│                             │                  │
│                             │  [リストを作成]    │
└─────────────────────────────┴──────────────────┘
```

- **左**：曲を探して**クリックで選ぶ**（もう一度クリックで解除）
- **右**：選んだ曲が並ぶ。ここで順番を整えて、最後に書き出し

スマホでは上下に並びます（上：曲を探す／下：選択中リスト）。

## 使いかた 6パターン

### ① 自分のチャンネルの曲だけから選ぶ

他のメンバーが歌った曲も全部入っているので、まず自分の持ち歌だけに絞ります。

1. 左上の「**全チャンネル**」から**自分のチャンネル**を選ぶ
2. 曲数の表示が減り、自分が歌ったことのある曲だけになります

> 以降のすべてのパターンと組み合わせられます。
> 「まずチャンネルを選ぶ」を基本にすると迷いません。

---

### ② とりあえず全部おまかせ（完全ランダム）

「考えるのが面倒！」というときに。

1. 右の「**目標**」に歌枠の長さを入力（例：`60` 分）
2. 「**指定時間まで補充**」を押す

→ その時間ぶん、ランダムに曲が入ります。

気に入らなければ「**引き直す**」を押すと、**中身を全部入れ替えて**引き直します。
好きな並びが出るまで何度でも押して大丈夫です。

> **「指定時間まで補充」と「引き直す」のちがい**
> - **指定時間まで補充**＝今選んでいる曲は**そのまま残して**、足りないぶんを足す
> - **引き直す**＝いったん**全部消して**、まるごと新しく引き直す

---

### ③ 「〇〇縛り」にする（アーティストで絞る）

例：**ヨルシカ縛り**の歌枠にしたい。

1. 検索ボックスに `ヨルシカ` と入力
2. 左のリストがヨルシカの曲だけになる
3. そのままクリックで選ぶ／または②の「指定時間まで補充」でランダムに詰める

検索は**曲名でもアーティスト名でも**引っかかります。
ひらがな・カタカナはどちらで打っても大丈夫です（`ヨルシカ` でも `よるしか` でも OK）。

---

### ④ 「アニメ縛り」にする（ジャンルで絞る）

タグをクリックするだけです。

1. 検索ボックスの下の「**アニメ**」タグをクリック（押すと色が変わります）
2. アニメ関連の曲だけになる

使えるタグ：
`アニメ` `ボカロ` `ゲーム` `特撮` `アイドル` `J-POP` `K-POP` `洋楽` `東方` `同人` `オリジナル` `バラード`

**複数選ぶと「どれか1つでも当てはまる曲」**が出ます。
例：`アニメ` ＋ `ボカロ` → アニメ**または**ボカロの曲（両方に当てはまる曲も入ります）。

もう一度クリックすると解除できます。

---

### ⑤ 順番を整える

選択中リストの中で、歌う順番を自由に入れ替えられます。

- **ドラッグ**：行の左にある「**⠿**」をつかんで、上下にドラッグ
- **ボタン**：右側の「**▲**」「**▼**」で1つずつ移動
- **削除**：「**✕**」でその曲だけ外す
- **全部消す**：右上の「**クリア**」

> 盛り上げ曲を最後に持ってくる、バラードを中盤にまとめる、など
> 実際の流れをイメージしながら並べ替えてください。

---

### ⑥ 時間を決めて自動で組む（①③④と組み合わせ）

このツールの本命です。**絞り込みと自動生成は組み合わせて使えます。**

例：**「アニメ縛りで、自分の持ち歌から、90分ぶん」**

1. チャンネル → **自分のチャンネル**（①）
2. タグ → **アニメ** をクリック（④）
3. 目標 → `90` 分
4. 「**指定時間まで補充**」

→ 条件に合う曲だけから、90分ぶんランダムに組まれます。

**「この曲は絶対歌いたい」がある場合：**

1. 先にその曲をクリックして選んでおく
2. そのあと「**指定時間まで補充**」

→ 選んだ曲は**残したまま**、残り時間ぶんが足されます。

> 表示される時間は**原曲の長さの合計**です。
> MC・雑談・曲間は含まれないので、実際の配信はこれより長くなります。
> 少なめに見積もっておくと安心です。

---

## 書き出し

1. 「**リストを作成**」を押す
2. テキストが表示されるので「**リストをコピー**」

こんな形式で出ます：

```
花に亡霊 / ヨルシカ
ただ君に晴れ / ヨルシカ
晴る / ヨルシカ
```

そのまま配信メモ、概要欄、コメント欄などに貼り付けてお使いください。

> **並べ替えた順番のまま**書き出されます。順番を整えてからコピーしてください。

## よくある質問

**Q. 作ったセトリは残りますか？**
A. 残りません。ページを閉じると消えます。**必ずコピーして**保存してください。

**Q. スマホでも使えますか？**
A. 使えます。ドラッグでの並べ替えもできますが、細かい操作は「▲▼」ボタンのほうが確実です。

**Q. 新しく歌った曲はいつ入りますか？**
A. その歌枠のセトリが登録されると、**自動的にこのリストにも追加**されます。
次に開いたときから選べるようになります。

**Q. 前より曲数が減っている気がします**
A. 同じ曲が**別の表記で重複登録**されていたと分かった場合、
1曲にまとめているためです（例：`traumerei` と `träumerei`、
英語表記と日本語表記など）。曲そのものが消えたわけではありません。

**Q. 曲が見つかりません／曲名やアーティストが違う気がします**
A. データの誤りかもしれません。下記からご連絡ください。
